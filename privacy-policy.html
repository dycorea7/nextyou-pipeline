Privacy Policy

NextYou Content Pipeline

Last updated: July 27, 2026  ·  Operated by Dong Yeop Lee, individual creator

NextYou Content Pipeline is a private, single-user tool used by its operator to publish original video content to the operator's own YouTube channel. It is not distributed, has no other users, and collects no personal data from anyone.

What this tool is

NextYou Content Pipeline is an automation workflow that I built and run for my own use. It assembles video content that I create — script, narration audio, and finished video — and, after I personally review and approve each item, uploads it to the YouTube channel I own and operate at https://www.youtube.com/@NextYouGlobal-i9w.

The tool runs on a private, self-hosted instance. There is no public interface, no sign-up, and no way for another person to access or use it.

Information collected

I do not collect, request, or receive personal information from any user, because there are no users other than me.

Specifically, this tool does not:

  • Collect names, email addresses, or contact details from anyone;
  • Read, store, display, or redistribute YouTube data belonging to other channels, videos, or viewers;
  • Use cookies, analytics, tracking pixels, or advertising identifiers;
  • Sell, rent, or share any data with third parties.

YouTube API Services

This tool uses YouTube API Services. By using it, I am subject to the YouTube Terms of Service, and the handling of data by Google is described in the Google Privacy Policy.

The only API method used is videos.insert, which uploads a video file to my own channel. No other YouTube API method is called, and no YouTube user data is retrieved.

Authorization and credentials

Access to my own YouTube channel is granted through Google OAuth, authorized by me for my own account. The resulting access and refresh tokens are stored in encrypted form within my private self-hosted workflow instance and are used only to upload videos to my channel.

Tokens are never shared with any third party. I may revoke this access at any time through my Google Account permissions page at myaccount.google.com/permissions, which immediately ends the tool's access.

Data retention

The tool retains only the material needed for its own operation: the content I authored, the generated audio and video files, and a record of which items have been published. No third-party or viewer data is retained, because none is ever obtained. Stored OAuth tokens are deleted when access is revoked or when the workflow is removed.

Children's privacy

This tool is not directed to children and does not knowingly collect information from anyone, including children under 13.

Changes to this policy

If the tool's functionality changes in a way that affects this policy, this page will be updated and the date above revised.
